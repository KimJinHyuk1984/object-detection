01 / CONNECT8분

모델과 앱을 연결하는 방법

주행영상을 올리면
모델의 결과를 영상으로 볼 수 있을까요?

  • 영상 → 프레임 → API → 결과 영상의 흐름을 설명합니다.
  • 구간과 초당 분석 프레임 수를 정해 앱을 실행합니다.
  • 객체 박스와 도로 영역을 확인하고 결과를 저장합니다.

결과물: 업로드 영상 테스트 + 조건 비교 기록 + 결과 MP4

  1. 입력영상 업로드

    구간을 고르고 프레임을 추출합니다.

  2. 요청·응답Roboflow API

    각 프레임을 같은 모델에 보내 종류·위치·영역을 받습니다.

  3. 표시박스와 마스크

    프레임에 겹쳐 그리고 MP4로 저장합니다.

모델에는 영상에서 추출한 이미지 한 장씩 보냅니다.

  • 영상 업로드 확인모델 없이 업로드·추출·MP4 저장을 확인합니다. 검출 결과는 없습니다.
  • 예제 결과로 연습가상 도로와 미리 작성한 예측으로 박스·마스크를 연습합니다.
  • 내 모델로 분석학습 후 실제 영상 프레임을 API에 보냅니다.

업로드 확인과 가상 예제를 실제 모델 성능으로 발표하지 않습니다.

실습 ZIP 받기 ↓ · 실행 안내

Python 3.12를 준비하고, 압축을 푼 app.py가 있는 폴더에서 터미널을 엽니다. 사용하는 터미널에 맞는 명령 한 가지를 선택합니다.

PowerShell

py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
CMD(명령 프롬프트)에서 실행하기
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py

각 명령이 끝난 뒤 다음 명령을 실행합니다. 처음 설치는 수업 전에 마칩니다. 실행 후 터미널의 Local URL을 엽니다.

  1. “영상 업로드 확인”에서 source.mp4를 선택합니다.

    모델이나 API 키 없이 원본 정보를 확인합니다.

  2. 0초부터 10초·2fps로 추출합니다.

    최대 20프레임이며 원본 시각이 표시됩니다.

  3. “결과 영상 만들기”를 누릅니다.

    재생·저장을 확인합니다. NO MODEL은 아직 미분석이라는 뜻입니다.

학습이 끝난 뒤 .streamlit/secrets.toml.example을 secrets.toml로 복사하고 본인 컴퓨터에서 값을 채웁니다.

# 이 파일을 secrets.toml로 복사한 뒤 실제 값은 로컬에서만 입력합니다.
ROBOFLOW_API_KEY = ""
ROBOFLOW_MODEL_ID = ""

모델 ID는 프로젝트와 버전을 고르는 값, API 키는 요청 권한을 확인하는 비밀값입니다. 설정 후 앱을 다시 시작합니다.

연결 정보 확인 전에는 모델 없이 실행할 수 있습니다. 실제 키를 코드·활동지·캡처에 넣지 않습니다.

03 / REQUEST10분

영상 프레임을 보내고 응답 읽기

  • “내 모델로 분석” → “영상 업로드”를 선택합니다.
  • MP4·MOV·AVI, 최대 200MB를 받습니다.
  • 한 번에 최대 20초·60프레임, 긴 변 960px로 분석합니다.
  • 10초·2fps는 프레임별 요청이 최대 20회입니다.

“영상 분석 실행”을 누르면 추출한 프레임들이 Roboflow로 전송됩니다.

YouTube 링크는 강의 시청용이며 모델 테스트는 로컬 영상 파일로 합니다.

infer_image() 내부의 실제 요청 부분입니다. image는 영상에서 추출하고 크기를 줄인 프레임, model_id는 프로젝트/버전, api_key는 비밀 설정에서 읽은 값입니다.

        client = InferenceHTTPClient(
            api_url="https://serverless.roboflow.com",
            api_key=api_key,
        )
        client.configure(InferenceConfiguration(
            confidence_threshold=MIN_CONFIDENCE, response_mask_format="polygon",
            api_key_transport="header", disable_active_learning=True,
        ))
        return client.infer(image, model_id=model_id)

마스크는 polygon 형식으로 요청합니다. 아래 코드는 배포한 core.py의 동일한 부분입니다.

CLASS · CONFIDENCE

무엇을 찾았나?

종류와 예측별 점수입니다. 점수는 전체 모델의 정답률과 다릅니다.

X · Y · WIDTH · HEIGHT

어디에 있나?

박스의 중심과 가로·세로 크기입니다.

POINTS

영역의 모양은?

line 경계를 따라 놓인 꼭짓점들입니다.

API가 돌려준 좌표를 이미지에 그리는 작업은 앱에서 합니다.

L3-CAPTURE-02분할 모델 준비 후 API 연결 정보

현재 탐지 모델의 유형과 평가 화면은 확인했습니다. 도로 마스크용 분할 모델을 준비한 뒤 Deploy Model의 실제 model_id·요청 코드·Serverless 지원 안내를 확인합니다. API 키는 캡처하지 않습니다.

기존 탐지 모델을 먼저 시험하는 경우에도 실제 요청 코드를 확인하며, 이 모델에서는 line 마스크가 나오지 않는다는 점을 구분합니다.

04 / DISPLAY14분

박스와 도로 마스크 그리기

왼쪽 = x − width / 2
위쪽 = y − height / 2

오른쪽과 아래쪽은 각각 절반 크기를 더합니다. x·y를 왼쪽 위 모서리로 해석하면 박스가 어긋납니다.

계산 확인하기

설명용 중심 (100, 80), 크기 (40, 20)이라면 왼쪽 위는 (80, 70), 오른쪽 아래는 (120, 90)입니다.

  • points를 순서대로 이어 도로의 경계를 만듭니다.
  • 반투명 색을 덮어 원본 도로가 함께 보이게 합니다.
  • 폴리곤이 없으면 모델 유형·응답을 확인합니다.

도로 마스크가 없다고 박스를 채워 대신 표시하면, 영역의 모양을 확인할 수 없습니다.

line의 의미는 차선 사이의 주행 가능한 도로 영역입니다. 객체 박스와 마스크 모두 같은 모델 응답에서 가져옵니다.

새 분석이 필요한 변경

  • 영상·구간·분석 fps 변경
  • 실행 모드 변경
  • 모델 ID·키 변경

받은 결과로 바꾸는 표시

  • confidence 임계값
  • 불투명도·클래스 선택
  • 확인할 프레임 선택

표시만 바꿀 때는 API를 다시 요청하지 않습니다. 변경한 표시로 MP4를 다시 만들 수 있습니다.

짝 활동 · 5분

  1. 학습 전에는 “예제 결과로 연습”을 선택합니다.

    모든 클래스에서 0.40 / 0.70 / 0.90의 표시 개수를 비교합니다.

  2. 학습 후에는 같은 영상 프레임으로 비교합니다.

    line의 경계·놓친 객체·오탐을 기록합니다.

  3. 업로드한 영상의 결과 MP4를 저장합니다.

    선택 fps의 무음 확인 영상입니다. 모델 연결 여부를 구분합니다.

L3-CAPTURE-03조건 비교와 저장 결과

학습 전에는 예제에서 0.40과 0.90을 비교합니다. 학습 후에는 같은 영상·시각·클래스에서 비교하고 결과 MP4를 확인합니다.

05 / REVIEW8분

결과와 오류를 확인하기

  • 설정 없음모델 ID·키 설정을 확인합니다. 예제 모드는 키 없이 동작합니다.
  • 요청 실패키 권한·모델 버전·Serverless 지원·네트워크를 확인합니다.
  • 결과 0개응답과 표시 임계값·클래스 선택을 살펴봅니다.
  • line 폴리곤 없음분할 모델과 points 응답을 확인합니다.

설정 오류와 모델의 인식 오류는 서로 다른 문제입니다.

  1. 10초 구간을 2fps와 5fps로 분석하면 요청 수는 어떻게 달라질까요?
  2. 도로 불투명도를 바꾸면 모델의 예측도 바뀌나요?
  3. 같은 프레임에서 놓친 객체와 도로 경계를 어떻게 확인할까요?
