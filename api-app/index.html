실습 앱은 준비된 코드에서 출발합니다. 학습 결과나 실제 API 성공 화면은 아직 제공되지 않았습니다.

01 / CONNECT8분

모델과 앱을 연결하는 방법

모델의 예측을
내가 쓰는 화면으로 옮길 수 있을까요?

  • 이미지 → API → 예측 → 화면의 흐름을 설명합니다.
  • 준비된 앱을 실행하고 객체 박스와 도로 영역을 표시합니다.
  • 표시 조건을 비교하고 오류 원인을 기록합니다.

결과물: 이미지 분석 앱 실행 + 조건 비교 기록 + 결과 PNG

  1. 입력이미지 한 장

    Streamlit에서 파일을 선택합니다.

  2. 요청·응답Roboflow API

    학습한 모델이 종류·위치·영역을 반환합니다.

  3. 표시박스와 마스크

    앱에서 결과를 이미지에 겹쳐 그립니다.

학습은 모델을 만드는 과정이고, 추론은 준비된 모델로 새 이미지를 분석하는 과정입니다.

예제 결과로 연습

가상 도로와 미리 작성한 결과를 사용합니다. API 키·완성 모델 없이 실행할 수 있습니다.

내 모델로 분석

학습 완료 후 모델 ID와 키를 설정하고 이미지를 전송합니다. 현재 실제 모델 연결은 확인 전입니다.

예제 화면의 숫자를 우리 모델의 성능으로 발표하지 않습니다.

02 / RUN10분

실습 앱을 실행하기

  • app.py이미지 선택·분석 버튼·표시 설정·결과 저장
  • core.py입력 보정·API 요청·좌표 확인·박스와 마스크 그리기
  • demo.py모델 없이 연습할 가상 장면과 수업용 결과
  • requirements.txt실습에 필요한 패키지와 검사에 사용한 버전

실습 ZIP 받기 ↓ · 실행 안내

Python 3.12를 준비하고, 압축을 푼 app.py가 있는 폴더에서 PowerShell을 엽니다.

py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py

각 명령이 끝난 뒤 다음 명령을 실행합니다. 처음 설치는 수업 전에 마칩니다. 실행 후 터미널의 Local URL을 엽니다.

  1. 실행 모드를 확인합니다.

    기본값은 “예제 결과로 연습”입니다.

  2. “예제 결과 보기”를 누릅니다.

    입력 이미지와 결과를 비교합니다. DEMO 문구가 표시됩니다.

  3. 도로 영역과 표지판을 찾습니다.

    line은 반투명 영역, sign 등 일반 객체는 박스입니다.

학습이 끝난 뒤 .streamlit/secrets.toml.example을 secrets.toml로 복사하고 본인 컴퓨터에서 값을 채웁니다.

# 이 파일을 secrets.toml로 복사한 뒤 실제 값은 로컬에서만 입력합니다.
ROBOFLOW_API_KEY = ""
ROBOFLOW_MODEL_ID = ""

모델 ID는 프로젝트와 버전을 고르는 값, API 키는 요청 권한을 확인하는 비밀값입니다. 설정 후 앱을 다시 시작합니다.

현재는 예제 모드로 진행합니다. 실제 키를 코드·활동지·캡처에 넣지 않습니다.

L3-CAPTURE-01앱 실행 화면

예제 모드 이름·DEMO 안내·입력 이미지·실행 버튼이 보이는 화면입니다. 앱을 실행한 뒤 저장하면 됩니다.

03 / REQUEST10분

이미지를 보내고 응답 읽기

  • JPG·PNG·WebP 한 장, 10MB·1,600만 화소 이하를 받습니다.
  • 방향을 보정하고 긴 변을 최대 1,600px로 줄입니다.
  • “분석 실행”을 누르면 처리한 이미지가 Roboflow로 전송됩니다.

화면에 그릴 좌표도 API에 보낸 이미지 크기를 기준으로 맞춰야 합니다.

우리 모델이 준비되기 전에는 예제 결과로 응답의 구조를 읽습니다.

infer_image() 내부의 실제 요청 부분입니다. image는 처리한 이미지, model_id는 프로젝트/버전, api_key는 비밀 설정에서 읽은 값입니다.

        client = InferenceHTTPClient(
            api_url="https://serverless.roboflow.com",
            api_key=api_key,
        )
        client.configure(InferenceConfiguration(
            confidence_threshold=MIN_CONFIDENCE, response_mask_format="polygon",
            api_key_transport="header", disable_active_learning=True,
        ))
        return client.infer(image, model_id=model_id)

마스크는 polygon 형식으로 요청합니다. 아래 코드는 배포한 core.py의 동일한 부분입니다.

CLASS · CONFIDENCE

무엇을 찾았나?

종류와 예측별 점수입니다. 점수는 전체 모델의 정답률과 다릅니다.

X · Y · WIDTH · HEIGHT

어디에 있나?

박스의 중심과 가로·세로 크기입니다.

POINTS

영역의 모양은?

line 경계를 따라 놓인 꼭짓점들입니다.

API가 돌려준 좌표를 이미지에 그리는 작업은 앱에서 합니다.

L3-CAPTURE-02실제 모델 설정 확인 · 학습 후

모델 ID·Instance Segmentation 유형·Deploy의 Serverless 지원 안내를 확인합니다. API 키는 캡처하지 않습니다. 현재 어노테이션 중에는 이 화면을 준비하지 않아도 됩니다.

04 / DISPLAY14분

박스와 도로 마스크 그리기

왼쪽 = x − width / 2
위쪽 = y − height / 2

오른쪽과 아래쪽은 각각 절반 크기를 더합니다. x·y를 왼쪽 위 모서리로 해석하면 박스가 어긋납니다.

계산 확인하기

설명용 중심 (100, 80), 크기 (40, 20)이라면 왼쪽 위는 (80, 70), 오른쪽 아래는 (120, 90)입니다.

  • points를 순서대로 이어 도로의 경계를 만듭니다.
  • 반투명 색을 덮어 원본 도로가 함께 보이게 합니다.
  • 폴리곤이 없으면 모델 유형·응답을 확인합니다.

도로 마스크가 없다고 박스를 채워 대신 표시하면, 영역의 모양을 확인할 수 없습니다.

line의 의미는 차선 사이의 주행 가능한 도로 영역입니다. 객체 박스와 마스크 모두 같은 모델 응답에서 가져옵니다.

새 분석이 필요한 변경

  • 입력 이미지 변경
  • 예제 / 실제 모드 변경
  • 모델 ID·키 변경

받은 결과로 바꿀 수 있는 표시

  • confidence 임계값
  • 도로 영역의 불투명도
  • 표시할 클래스 선택

이 앱은 결과를 세션에 보관합니다. 표시만 바꿀 때는 API를 다시 요청하지 않습니다.

짝 활동 · 5분

  1. 예제에서 모든 클래스를 선택합니다.

    표시 임계값 0.40 / 0.70 / 0.90의 객체·도로 영역 개수를 활동지에 기록합니다.

  2. line만 선택하고 불투명도를 바꿉니다.

    모델의 점수가 바뀌는지, 표시만 바뀌는지 구분합니다.

  3. 결과 PNG를 저장합니다.

    예제임을 알리는 DEMO 문구와 적용 조건을 함께 확인합니다.

L3-CAPTURE-03조건 비교와 저장 결과

같은 예제 이미지에서 0.40과 0.90의 결과를 각각 저장합니다. 선택 클래스·임계값·DEMO 안내가 보이면 됩니다. 실제 모델 결과와 구분합니다.

05 / REVIEW8분

결과와 오류를 확인하기

  • 설정 없음모델 ID·키 설정을 확인합니다. 예제 모드는 키 없이 동작합니다.
  • 요청 실패키 권한·모델 버전·Serverless 지원·네트워크를 확인합니다.
  • 결과 0개응답과 표시 임계값·클래스 선택을 살펴봅니다.
  • line 폴리곤 없음분할 모델과 points 응답을 확인합니다.

설정 오류와 모델의 인식 오류는 서로 다른 문제입니다.

  1. 모델 ID와 API 키는 어떤 역할이 다른가요?
  2. 도로 불투명도를 바꾸면 모델의 예측도 바뀌나요?
  3. 영상의 모든 프레임을 API에 보내면 시간·사용량은 어떻게 달라질까요?
