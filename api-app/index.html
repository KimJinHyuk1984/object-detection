Instance Segmentation 모델이 들어 있는 Workflow를 준비하고 연결 설정에 값을 입력합니다.

Workspace ID: Deploy Workflow의 workspace_name
Workflow ID: Deploy Workflow의 workflow_id
Private API Key: 앱 입력창에만 입력 (캡처하지 않음)

기본 입력 이름은 image, 출력 이름은 predictions입니다. Outputs에서 모델의 Predictions를 선택합니다.

모델 표시 이름·Model URL은 Workflow ID가 아닙니다. API 키를 캡처·활동지·코드에 넣지 않습니다.

03 / REQUEST10분

영상 프레임을 보내고 응답 읽기

  • MP4(H.264) 영상을 선택하고 분석 시작을 누릅니다.
  • 기본 초당 2회, 긴 변 640px, 8장 묶음으로 요청합니다.
  • 3분은 360장 → 8장씩 순차 처리하면 약 45개 HTTP 요청입니다.
  • 먼저 완료된 구간부터 재생하며 미분석 구간은 잠시 기다립니다.

HTTP 요청 수와 처리 이미지 사용량은 다릅니다. 360장은 여전히 360장입니다.

참고 템플릿의 base64 이미지 배열·Bearer 헤더 연결 방식을 사용합니다. 아래는 배포하는 workflow.py의 실제 요청 코드입니다.

        response = requests.post(
            f"{API_URL}/{workspace}/workflows/{workflow}",
            headers={"Authorization": f"Bearer {api_key.strip()}"},
            json={"inputs": {input_name: [
                {"type": "base64", "value": frame["jpeg"]} for frame in frames
            ]}},
            timeout=(10, 90),
        )

한 번에 전체 영상을 보내지 않고 작은 묶음으로 처리합니다. 이미지 입력 이름은 Workflow 설정과 일치해야 합니다.

CLASS · CONFIDENCE

종류와 신뢰도

0.92를 92%로 표시합니다. 전체 모델 정확도와 다릅니다.

X · Y · WIDTH · HEIGHT

객체의 위치

중심 좌표와 가로·세로 크기로 박스를 만듭니다.

POINTS

도로 영역

꼭짓점을 연결해 반투명 마스크를 그립니다.

브라우저는 현재 영상 시각에 맞는 결과만 표시합니다.

04 / DISPLAY14분

박스와 도로 마스크 그리기

  • car · motor · people · sign객체 박스와 예측 신뢰도(%)를 표시합니다.
  • lampg · lampr · lampy · lamp신호등 박스·퍼센트와 큰 신호 안내를 표시합니다.
  • line주행 가능한 도로 영역을 반투명 파랑으로 채우고 퍼센트를 표시합니다.

화면 예제에서 멈춘 뒤 같은 장면의 표시를 비교합니다.

왼쪽 = x − width / 2
위쪽 = y − height / 2

오른쪽과 아래쪽은 절반 크기를 더합니다. 분석 이미지와 영상의 크기가 다르면 비율에 맞춰 좌표를 바꿉니다.

계산 확인

중심 (100, 80), 크기 (40, 20)이면 왼쪽 위는 (80, 70), 오른쪽 아래는 (120, 90)입니다.

  • points를 순서대로 연결해 도로 경계를 만듭니다.
  • 반투명 색과 경계를 원본 영상 위에 겹칩니다.
  • 폴리곤이 없으면 분할 모델·Workflow 출력을 확인합니다.

line을 박스로 대신 채우지 않습니다.

차선 사이의 주행 가능 도로 영역이며, 도색된 선을 뜻하지 않습니다.
