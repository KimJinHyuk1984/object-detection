이 값은 모델이 각 예측에 부여한 점수입니다. 전체 모델의 정답률과 같은 값으로 해석하지 않습니다.

표시 임계값을 높이면 낮은 점수의 예측이 빠집니다. 잘못된 예측이 줄 수도 있지만 필요한 객체까지 사라질 수 있습니다.

생각 확인하기

Valid 이미지에서 임계값을 바꾸며 무엇이 사라지는지 비교합니다. 비교할 때 같은 이미지와 조건을 유지하고, Test를 반복 조정용으로 사용하지 않습니다.

PRECISION

찾았다고 한 것 중

맞게 찾은 비율입니다.

TP / (TP + FP)

RECALL

실제로 있는 것 중

놓치지 않고 찾은 비율입니다.

TP / (TP + FN)

mAP

클래스별 성능 종합

여러 임계값에서 Precision·Recall을 요약한 AP를 클래스별로 평균냅니다. Box / Mask와 IoU 기준을 함께 읽습니다.

TP: 올바른 탐지 · FP: 잘못된 탐지 · FN: 놓친 정답. 같은 클래스인지와 위치·영역의 겹침 기준으로 대응을 판단합니다.

생각 확인하기

설명용 예: 정답 12개 중 8개를 찾고 잘못된 예측 2개가 더 있다면, Precision은 8/10 = 80%, Recall은 8/12 ≈ 66.7%입니다. 실제 모델 점수가 아닙니다.

Mask IoU

겹친 영역 ÷ 합친 영역

정답 64칸 + 예측 64칸 − 겹친 48칸 = 합친 80칸

48 / 80 = 0.60

박스의 겹침과 마스크의 겹침을 구분합니다. 도로 영역의 경계 품질은 마스크로 확인합니다.
