# 3차시 제작·앱 검증 기록

날짜: 2026-10-17  
판정: **3차시 강의·예제 앱·실습 ZIP·PDF 작성 완료. 실제 사용자 모델 연결과 브라우저 검증은 대기.**

사용자의 “다음작업하자” 요청에 따라 3차시를 제작했고, “아직 어노테이션 중” 답변을 반영했습니다. 실제 모델 학습 완료·API 성공·성능 수치를 가정하지 않았습니다.

## 산출물

- api-app/index.html: 5개 섹션, 18개 발표 조각, 8+10+10+14+8=50분.
- files/lesson-03/: Streamlit 앱·핵심 처리·가상 예제·의존성·실행 안내·빈 비밀 설정 예시.
- files/lesson-03.zip: 공개 실습 파일 9개, 원본과 바이트 일치.
- files/lesson-03-workbook.pdf: A4 2쪽, 한글 일반·굵은 글꼴 포함.
- assets/img/lesson-03/demo-result.png: 가상 장면과 손으로 작성한 예제 결과. DEMO 표시 포함.
- scripts/package_lesson03.py, scripts/create_lesson03_workbook.py: 생성 원본.
- tests/test_lesson03.py: 입력·좌표·마스크·SDK 경계·세션 상태 검사.
- 교사용 진행안과 캡처·확인 안내.

1·2차시의 발표 조각 내용은 변경하지 않았습니다. 전체 강의 목록과 차시 간 이동에 3차시 링크를 추가했습니다. 4차시는 준비 중입니다.

[정적·앱·산출물 결과](lesson-03-static-checks.json), [HTTP 결과](lesson-03-http-checks.json)에 근거를 기록했습니다.

- HTML 4개: 태그 짝·중복 ID·중첩 발표 조각·깨진 내부 참조 오류 0건. 로컬 참조 91개·앵커 20개 확인.
- 기존 1차시 21개·2차시 20개 발표 조각의 내용 보존. 3차시 18개와 각 50분 배분 확인.
- 강의 코드 3개와 실제 배포 파일의 해당 줄을 문자 단위로 비교해 일치.

- root 및 /object-detection/ 경로에서 HTML·자산·코드·다운로드 54개 응답 200·바이트 일치.
- Python 3.12.14와 Streamlit 1.66.0·inference-sdk 1.8.0·Pillow 12.3.0으로 테스트 8개 통과.

- PDF 페이지 크기·한글 글꼴 포함·텍스트·배포본 동일성 확인. ZIP의 실제 비밀 설정·캐시·가상환경 제외 확인.
- git diff --check 및 실제 git check-ignore 확인.

## 앱 테스트 범위

6개 핵심 처리 테스트와 2개 Streamlit AppTest 테스트입니다.

1. EXIF 방향과 투명 이미지의 흰 배경 처리.
2. 잘못된 파일·용량 제한·긴 변 축소.
3. 응답 좌표 배율과 폴리곤의 실제 픽셀 표시.
4. 빈 결과·잘못된 응답·NaN 점수·line 폴리곤 누락.
5. 임계값별 예제 결과 수와 이미지·모델·키 변경 식별.
6. SDK 호출 인자·polygon 설정·오류 원문의 비밀값 비노출.
7. 예제 모드·표시 변경·실제 모드 전환 시 결과 초기화.
8. 실제 모드의 대체 응답으로 호출 1회·재표시 시 미호출·모델 변경·실패 시 초기화.

실제 Roboflow 요청은 **0회**입니다. SDK 및 실제 모드의 호출 검사는 mock 응답으로 수행했습니다. AppTest의 업로드 입력도 테스트에서 대체한 이미지이며 실제 브라우저 파일 선택을 검증한 것은 아닙니다.

## 환경과 남은 확인

기본 셸 도구의 환경 초기화 실패로 Node REPL의 파일·프로세스 API를 사용했습니다. 번들 Python·Poppler를 사용했고 Python 패키지는 무시된 work-temp/lesson03/deps에 설치했습니다. 이 임시 설치 경로에서는 Streamlit이 개발 모드로 판단해, 서버 시작 검사에 developmentMode=false를 명시했습니다. 정상 가상환경 설치를 안내하는 사용자 앱 코드는 변경하지 않았습니다.

브라우저 인벤토리는 apps=[], browsers=[]여서 실제 화면·키보드·클립보드·모바일 검증은 수행하지 못했습니다. PDF와 예제 결과 PNG는 파일을 직접 렌더링해 시각 확인했습니다.

현재는 어노테이션을 계속합니다. 학습 완료 후 실제 모델 ID·분할 유형·Serverless 지원·line points 응답을 확인하고 실제 이미지 API 연결을 검증합니다. [캡처 안내](lesson-03-capture-guide.md)에 단계별 화면을 지정했습니다.

수행: 3차시 제작 → 산출물: 강의·앱·ZIP·PDF·안내 → 검사: 정적·자동 앱·HTTP·PDF 통과 / 실제 모델·브라우저 대기 → 다음: 실제 학습 결과 확인과 이후 영상 앱 차시. 커밋·푸시·학습·원격 프로젝트 수정·외부 배포는 수행하지 않았습니다.
