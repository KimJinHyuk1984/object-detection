## 2차시에 필요한 캡처

원본은 `captures/lesson-02/`에 저장합니다. 이 폴더는 Git 추적에서 제외됩니다. 화면 구성이 달라 여러 장이 필요하면 파일명 뒤에 번호를 붙입니다.

| 때 | 파일명 | 보여야 할 정보 | 확인할 것 |
| --- | --- | --- | --- |
| 검수 후 Dataset 반영 | 01-dataset.png | 이미지 수, 9개 클래스와 라벨 수 | Annotated 수와 Dataset 수를 구분. 클래스 이름만 있고 예시가 0개인 경우 확인 |
| 데이터 분리 후 | 01-split.png | Train·Valid·Test의 실제 이미지 수 | 같은 장면의 인접 프레임이 서로 다른 분리에 섞이지 않았는지 |
| 데이터 버전 생성 후 | 02-version.png | 버전 이름·번호, 전처리와 증강 설정 | 선택한 분리 유지, 작은 대상 보존, 신호등 색과 라벨의 일치 |
| 학습 시작/진행/완료 때 | 03-training.png | 분할 모델 종류, 버전, 실제 상태 | 대기·진행 중이면 그대로 기록. 완료한 것으로 표시하지 않음 |
| 학습 완료 후 | 04-metrics.png | 지표 이름과 값, Box/Mask, 데이터 분리 | mAP의 IoU 기준과 Valid/Test 구분. 화면에 없는 값은 추정하지 않음 |
| 예측 결과 확인 후 | 04-prediction.png | 이미지, 클래스·confidence, line 영역 | 잘 된 예와 오류를 확인. 정답 폴리곤 화면과 예측 마스크 화면 구분 |

수업에서는 이 6개 화면을 데이터·버전·학습·평가의 **4종 캡처 안내**로 묶었습니다. 한 화면에 정보가 함께 보이면 파일을 합쳐도 됩니다. 실제 결과가 나오지 않은 칸에는 설명용 값을 대신 넣지 않습니다.

계정 이메일·API 키가 나오지 않도록 필요한 프로젝트·설정·결과 영역을 캡처합니다. 받은 원본을 확인한 뒤 공개용 이미지만 별도로 강의에 반영합니다.
