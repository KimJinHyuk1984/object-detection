# 2차시 교사용 진행안

주제: 모델을 학습하고 평가하기 · 50분 · 20개 발표 조각  
페이지: [2차시](../model-training/index.html)  
상태: 사용자는 어노테이션 진행 중. 실제 학습 결과·2차시 캡처는 아직 없음.

## 수업 전 준비

- 프로젝트 유형과 기존 정답의 분할 학습 호환성을 확인합니다. 기존 캡처는 Object Detection이며, 단일 모델의 도로 마스크 출력을 목표로 합니다.
- 일반 객체도 분할 학습용 정답이 필요합니다. 실제 객체 윤곽과 사각형 영역은 다릅니다. 박스만 있는 데이터를 그대로 옮기는 것만으로 윤곽 마스크가 완성되지는 않습니다. 대표 이미지의 저장 형식을 먼저 확인합니다.
- 검수한 이미지와 9개 클래스의 예시 수를 점검합니다. 아직 작업 중이라면 계획·평가 개념 활동을 먼저 진행하고 실제 버전 생성과 학습은 검수 후 이어갑니다.
- source.mp4의 가까운 프레임을 같은 장면 묶음으로 두는 분리 계획을 준비합니다. 하나의 영상만 사용한 평가는 새로운 도로·날씨로 일반화한 성능의 증거가 되지 않습니다.
- 계정에서 제공하는 분할 모델·학습 옵션·크레딧을 확인하고 대표 학습 작업을 정합니다. 모델 이름·비용·완료 시간을 고정값으로 안내하지 않습니다.
- 학습 대기 시간이 길 수 있습니다. 사전에 학습한 실제 모델이 있으면 해당 버전임을 밝히고 평가에 사용합니다. 없다면 본문의 가상 사례로 연습하고 실측 지표 칸은 비워 둡니다.

## 50분 진행

| 시간 | 활동 | 학생 결과물 | 교사 확인 |
| --- | --- | --- | --- |
| 0–8분 | 정답·클래스·프로젝트 준비 확인 | 준비 체크와 클래스별 예시 점검 | 검수와 Dataset 반영 상태를 구분 |
| 8–18분 | Train·Valid·Test 및 장면 묶음 분리 | 4분 짝 활동: 장면 묶음·배정 이유 | 인접 프레임 누출, 희소 클래스 분포 |
| 18–26분 | 전처리 미리보기·버전 생성/계획 | 버전·분리·전처리·증강 기록 | 작은 신호등·표지판, 신호등 색 보존 |
| 26–36분 | 단일 분할 모델 학습 설정·실행 또는 설정 계획 | 모델·버전·시작 시각·실제 상태 | 완료를 기다리며 가상 오류 분석 |
| 36–50분 | 지표·Mask IoU·오류 분석·종료 질문 | 4분 짝 활동: 오류 한 가지와 개선안 | 실제 예측/가상 사례 구분, Valid로 비교 계획 |

각 구간의 설명·조작·전환 시간을 포함한 배분입니다. 준비 자료가 없으면 계획 활동으로 진행하며, 실습 완료로 표시하지 않습니다. 기다리는 시간을 별도로 더하지 않습니다.

## 설명 포인트

- Train은 가중치를 학습하고, Valid는 설정·임계값과 개선 방향을 비교하고, Test는 최종 확인에 사용합니다. 70/20/10과 A–D 100장 표는 설명용 예시입니다.
- 실제 분리는 영상·촬영 회차 단위가 우선입니다. 현재처럼 영상 하나라면 장면·시간 구간을 묶고 경계에 거의 같은 프레임이 있는지 점검합니다. 비율을 맞추려고 인접 프레임을 흩뜨리지 않습니다.
- 첫 기준 버전은 추가 데이터 증강 없이 만듭니다. 모델 자체의 학습 증강 설정이 표시되면 따로 기록합니다. 신호등 색으로 클래스를 구분하므로 흑백·색조 변경은 이 수업의 첫 버전에서 사용하지 않습니다.
- 모델은 하나로 학습하며, 일반 객체는 박스, line은 마스크로 표시하는 앱은 이후 차시에서 구현합니다. line은 도색된 차선이 아닌 차선 사이의 주행 가능 도로 영역입니다.
- confidence는 각 예측의 점수입니다. 전체 모델의 정확도나 보정된 확률로 단정하지 않습니다.
- mAP는 클래스별 AP의 평균이며 Box/Mask와 IoU 기준을 함께 읽습니다. Precision·Recall 예시의 정답 12개, TP 8개, FP 2개는 실제 모델 결과가 아닙니다.
- 격자 도식은 정답 64칸, 예측 64칸, 겹침 48칸입니다. 합집합 80칸, Mask IoU 0.60이며 실제 도로 예측을 재현한 그림이 아닙니다.
- 개선안은 한 번에 한 가지로 정하고 같은 Valid 이미지·조건으로 비교합니다. Test를 반복 조정에 사용하지 않습니다.
