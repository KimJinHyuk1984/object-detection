# 4차시 검증 기록
검사일: 2026-10-18

## 구현 범위
- [강의 페이지](../video-app/index.html): 5개 섹션·18개 발표 조각, 5+15+10+10+10=50분.
- 허브와 1–3차시에서 4차시 이동 가능. 전체 4차시 77개 발표 조각·200분.
- [활동지](../files/lesson-04-workbook.pdf): A4 3쪽. 생성 원본은 [create_lesson04_workbook.py](../scripts/create_lesson04_workbook.py).
- [교사용 진행안](lesson-04-teacher-guide.md), [캡처 목록](lesson-04-capture-guide.md), [공유 준비](lesson-04-sharing-guide.md) 작성.
- 신뢰도 40%/70%는 학생의 같은 장면 비교, 초당 2회/5회는 교사의 사전 측정 비교로 구성.
- 기존 실습 앱·ZIP과 보호 공통 자산·원본 영상은 변경하지 않음.

세부 값과 최종 PDF 해시는 [lesson-04-checks.json](lesson-04-checks.json)에 기록합니다. HTTP 검사는 파일 제공 여부를 검사한 것으로 실제 브라우저 클릭 검사가 아닙니다. 검사에 사용한 로컬 서버는 종료했습니다.

## 수행하지 않은 검사·작업
- 현재 연결된 앱·브라우저가 없어 발표 모드·테마·모바일·다운로드 클릭 등 브라우저 조작은 수행하지 못했습니다.
- 사용자 모델의 실제 Roboflow API 호출·처리 시간 측정·외부 배포·Git 커밋·푸시는 하지 않았습니다.
- 사용자가 앱의 정상 동작을 확인한 사실을 반영했으나, 분할 모델의 정확도·도로 마스크 품질·공유 환경 결과를 임의로 확정하지 않았습니다.
- 기존 앱은 수정하지 않아 앱 테스트를 다시 실행하지 않았습니다. 이전 앱 검사 결과는 [3차시 검증 기록](lesson-03-verification.md)을 참고합니다.

## 수업 전 실제 화면에서 확인할 것
1. index.html에서 4차시 카드가 열리는지, 1–3차시 이동 링크가 이어지는지 확인합니다.
2. 4차시에서 발표 모드 P, 방향키 이동, Esc 종료, 테마 전환을 확인합니다.
3. 교실 해상도와 좁은 화면에서 표·발표 내용이 잘리는지 봅니다. 발표 모드에서 reportPresentationOverflow() 결과도 확인합니다.
4. 활동지 PDF·실습 ZIP이 다운로드되는지 확인하고 PDF를 인쇄 미리보기로 확인합니다.
5. 새 영상 성공·실패 장면 2장, 신뢰도 비교 2장, 공유 확인 1장을 준비합니다.
6. 실제 배포 주소가 있으면 A, 없으면 사전 설치한 별도 PC에서 B를 진행합니다. A/B를 기록에서 구분합니다.
