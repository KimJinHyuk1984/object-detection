# 4차시 공유 체험 준비
[교사용 진행안](lesson-04-teacher-guide.md) · [실습 앱 실행 안내](../files/lesson-03/README.md)

4차시의 공유 활동은 10분입니다. 호스팅 가입·서버 설치·외부 배포 자체는 사전에 준비합니다. 이 저장소에는 실제 외부 배포 주소가 등록되어 있지 않습니다.

## 세 주소를 구분하기
| 대상 | 의미 | 수업에서 확인할 것 |
| --- | --- | --- |
| GitHub Pages 강의 주소 | HTML·CSS·JavaScript로 된 강의 자료 | 강의와 PDF 다운로드 |
| `http://127.0.0.1:7862` | 접속한 기기 자신의 Python 앱 | 해당 기기에서 서버 실행 필요 |
| 교사가 준비한 앱 주소 | 별도 서버에서 실행되는 Drive Vision | 다른 기기에서 접속·영상·실제 추론 확인 |

GitHub Pages는 정적 호스팅입니다. 저장소를 Pages로 게시하는 것만으로 Python API 서버가 실행되지는 않습니다. [GitHub 공식 설명](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

## A. 교사가 준비한 배포 주소로 체험
교사가 실제 배포를 준비한 경우에만 선택합니다. 학생은 교사가 배포한 주소를 받아 다른 기기에서 접속합니다. localhost 주소를 다른 사람에게 전달하는 것으로 대체하지 않습니다.

학생 10분 활동:
1. 앱 주소를 열고 화면이 정상 표시되는지 확인합니다.
2. 준비한 영상을 선택하고 재생·일시정지·탐색을 확인합니다.
3. 실제 Workflow 분석을 실행하고 MODEL RESULT에서 객체·도로 영역·신호 안내를 확인합니다.
4. 같은 재생 시각과 신뢰도 조건으로 자신의 결과와 비교합니다.
5. 환경·성공/실패·남은 문제를 활동지에 쓰고 `05-sharing-check.png`를 저장합니다.

실제 분석까지 확인하지 못하면 “화면/원본 재생만 확인”이라고 적습니다. 가상 예제 동작만으로 모델 연결 성공을 표시하지 않습니다.

### 교사의 배포 준비 체크
현재 실습 ZIP은 로컬 실행을 위해 `127.0.0.1:7862`에 바인딩하고 허용 호스트를 제한합니다. 아래 항목은 외부 배포 전 **구현·확인할 준비 목록**입니다. 현재 ZIP에 이미 적용되었다는 뜻이 아닙니다.

- Python 3.11/3.12와 requirements를 설치할 수 있고 서버 프로세스를 계속 실행할 수 있는 환경.
- 호스팅이 요구하는 포트·수신 주소와 앱의 허용 호스트를 실제 도메인에 맞게 설정.
- HTTPS와 수업 참여자 접근 범위·요청량 제한. 공개 추론 경로를 무제한으로 열지 않도록 설정.
- API 키를 서버의 비밀 환경변수 등으로 관리하고 공개 파일·스크린샷·Git에 포함하지 않음.
- Roboflow 연결·요청 시간 제한·재시작·동시 사용자 수를 수업 전에 확인.
- 교실의 다른 기기에서 재생 및 실제 추론 시험. 브라우저에서 만드는 JPEG 이미지가 앱 서버를 거쳐 Roboflow로 전송되는 경로를 안내.
- 학생 수에 맞는 사용량과 운영 시간을 사전 확인하고 종료 후 운영 방식을 정함.

Python API 배포에는 서버 실행, HTTPS, 재시작, 자원 관리 등이 필요합니다. 자세한 항목은 [FastAPI 배포 개념](https://fastapi.tiangolo.com/deployment/concepts/)을 참고합니다. 특정 서비스의 무료 요금·지원 범위를 전제로 하지 않습니다.

## B. 별도 PC에서 같은 ZIP 실행
외부 배포 주소가 준비되지 않은 경우의 대체 활동입니다. 설치를 마친 다른 PC에 같은 버전의 [실습 ZIP](../files/lesson-03.zip)을 풀고 [실행 안내](../files/lesson-03/README.md)에 따라 서버를 실행합니다.

학생은 **별도 PC에서** 해당 PC의 `http://127.0.0.1:7862`를 엽니다. A와 동일한 영상·재생 시각·신뢰도·Workflow/모델을 사용해 결과를 확인합니다. 활동지에는 “B · 별도 PC 실행”으로 기록합니다. 이는 재현 확인이며 외부 배포 완료가 아닙니다.

둘 다 준비하지 못한 경우 교사의 실제 저장 결과를 관찰할 수 있으나, 활동지에는 “공유 환경 직접 확인 못 함”과 다음에 확인할 항목을 남깁니다.

## 수업 후 남길 기록
- 사용 방식 A/B/직접 확인 못 함.
- 앱 주소 또는 사용 PC 이름, 날짜, 앱 버전/ZIP 식별 정보.
- 영상과 Workflow·모델 버전, 확인한 범위.
- 실행·재생·실제 결과 여부, 남은 오류.
- 다음 조치 한 가지. 실제 URL·처리 시간·모델 성능은 직접 확인한 값만 기록.
