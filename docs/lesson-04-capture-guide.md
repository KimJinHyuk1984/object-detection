성공·실패 PNG 2장은 활동지와 함께 제출합니다. 비교 2장·공유 1장은 수업 기록용입니다. 앱의 PNG 저장 버튼은 영상 위 오버레이 기록에 사용할 수 있습니다. 설정·상태·주소까지 증거가 필요하면 전체 앱 창을 별도로 캡처하거나 활동지에 조건을 함께 적습니다.

## 교사가 수업 전에 확보할 자료
- [ ] 새 영상의 파일명·길이와 학습에 사용하지 않았다는 근거.
- [ ] 객체 박스, line 도로 마스크, 신호 안내가 보이는 실제 결과. 한 화면에 모두 없으면 별도 장면으로 준비.
- [ ] 실제 실패 사례 1개 이상. 모델이 놓친 대상과 사람이 확인한 내용을 표시.
- [ ] 같은 영상·모델·배치 8장으로 완료한 초당 2회/5회 분석의 실제 처리 시간. 측정 시작/종료 기준도 기록.
- [ ] Workflow에 연결된 **프로젝트/모델 버전**. Workflow 이름만 같아도 내부 모델이 바뀔 수 있음.
- [ ] A 방식이면 다른 기기에서 실제 배포 주소와 분석 연결을 사전 확인. B 방식이면 별도 PC에서 같은 ZIP으로 실행 확인.

## 촬영 전에 확인
1. DEMO / NO RESULT / MODEL RESULT를 확인합니다. 실제 평가 캡처는 MODEL RESULT에서 촬영합니다.
2. 분석 완료 구간에서 일시정지하고 영상명·시각·신뢰도 기준·분석 빈도를 활동지에 적습니다.
3. `line`은 주행 가능한 도로 영역입니다. 도로 마스크가 차량·인도 등 포함하면 해당 정답 기준에 따라 오류 여부를 설명합니다.
4. API 키 입력, 인증 헤더, 비밀 환경변수는 촬영하지 않습니다. 영상 공유본에 드러나는 개인 정보는 필요한 범위에서 가립니다.
5. 신호 안내가 바뀌는 장면은 색·안내 문구·같은 시각의 인식 결과를 함께 확인합니다. 영상에 없는 색은 확인한 것으로 체크하지 않습니다.

사진을 추가한 뒤 확인할 작업: 파일명과 실제 내용 일치, 글자 읽힘, 원본 비율 유지, 캡처의 조건과 활동지 기록 일치. 강의에는 실제로 받은 화면만 삽입합니다.
