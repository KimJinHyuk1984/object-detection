## 학습 전에 확인할 내용

- [ ] **모델 유형:** 현재 캡처는 Object Detection입니다. 폴리곤을 그려도 탐지 모델의 출력은 박스입니다. 목표인 도로 마스크 출력을 위해 기존 어노테이션을 보존하면서 Instance Segmentation 프로젝트·학습 형식으로 사용할 수 있는지 확인합니다. 프로젝트 전환·데이터 이동·학습은 실행하지 않았습니다.
- [x] **lamp의 의미:** 사용자가 신호등이지만 색을 구분하기 어려운 경우라고 확정했습니다. 초록은 lampg, 빨강은 lampr, 노랑은 lampy로 구분합니다.
- [ ] **일반 객체의 정답 형식:** car 캡처에는 박스가 보입니다. 표시 방식만으로 저장된 모든 클래스의 라벨 형식을 단정하지 않습니다. 분할 학습에 필요한 형식과 기존 어노테이션의 호환성을 확인합니다.
- [ ] **sign의 경계 규칙:** 어떤 표지판을 포함하는지, 표지판 판만 표시할지 지지대도 포함할지 기준을 정합니다.
- [ ] **line의 경계 규칙:** 캡처에는 여러 차로가 각각 폴리곤으로 표시되어 있습니다. 이를 전체 데이터에 적용할지, 차량·장애물 픽셀과 가려진 도로를 어떻게 처리할지 기준을 확인합니다.
- [ ] **저장 확인:** 작업한 이미지 한 장을 다시 열어 라벨이 유지되는지 확인합니다.

## 추가 캡처가 필요한 때

지금 자료로 도입·객체 박스·도로 영역 예시는 사용할 수 있습니다. 같은 화면을 다시 찍을 필요는 없습니다.
프로젝트 유형이나 라벨 구분을 정리한 뒤에는 변경된 프로젝트 정보와 클래스 목록을 캡처하면 강의의 최종 설정 예시로 교체할 수 있습니다.
도구 조작 또는 저장 완료를 화면으로 설명하려면, 계정 정보가 나오지 않도록 편집 영역·클래스 목록이 보이는 이미지 한 장을 다시 열어 캡처합니다.
완성 모델과 Streamlit 앱 화면은 모델·앱 제작 이후 추가합니다.

## 다음 작업 순서

1. **분할 학습용 프로젝트 준비:** 현재 캡처의 aicar는 Object Detection입니다. 워크스페이스의 프로젝트 ⋯ 메뉴에서 Duplicate Project를 열고 Instance Segmentation을 선택할 수 있는지 확인합니다. 복제 프로젝트 이름은 예를 들어 aicar-seg로 정합니다. 원본 aicar는 보존합니다. 메뉴나 유형 선택이 다르면 현재 복제 설정 화면을 확인한 뒤 방법을 정합니다.
2. **기존 정답 보존 확인:** 원본과 복제본의 이미지 수·9개 클래스·클래스별 라벨 수를 비교합니다. line 폴리곤, 자동차, 신호등, 표지판이 있는 대표 이미지를 열어 정답이 남아 있는지 확인합니다. 복제만으로 박스가 실제 객체 윤곽의 마스크가 되는 것은 아니므로 일반 객체의 분할 학습용 정답 형식도 확인합니다.
3. **1차시 기준 확정:** sign의 포함 범위·지지대 처리, line의 차로·장애물·가림 처리 기준을 정하고 대표 이미지 한 장을 검수합니다. 이후 남은 어노테이션을 같은 기준으로 진행합니다.
4. **1차시 화면 확인:** 실제 수업 브라우저에서 발표 모드, 표지판이 추가된 개념도·경계 기준, 이미지 확대와 글자 넘침을 확인합니다.
5. **2차시 제작·학습 준비:** 검수한 이미지를 학습용 데이터셋에 반영하고, 영상 구간을 고려한 학습·검증·시험 데이터 분리 → 버전 생성 → 학습 → 예측 오류 분석 흐름을 구체화합니다.

복제 메뉴와 프로젝트 유형 선택은 [Roboflow 지원 답변 — 복제 메뉴](https://discuss.roboflow.com/t/how-do-i-duplicate-a-project/3488), [복제 시 유형 선택](https://discuss.roboflow.com/t/copying-all-images-from-a-segementation-to-a-new-project-for-detection/6710)을 근거로 안내했습니다. 현재 사용자 계정의 메뉴·복제 결과는 확인하지 않았으며, 여기서 Roboflow 프로젝트를 변경한 것은 아닙니다.
