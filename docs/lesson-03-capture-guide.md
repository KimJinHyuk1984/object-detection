## 꼭 확인할 항목

- [ ] python app.py 실행 후 http://127.0.0.1:7862가 열린다.
- [ ] 3분 영상을 자르지 않고 선택해 원본을 바로 재생할 수 있다.
- [ ] 화면 예제는 API 없이 작동하고 DEMO 표시가 보인다.
- [ ] 실제 Workflow의 입력 이름·출력 이름이 앱 설정과 일치한다.
- [ ] 분석 첫 묶음부터 영상 위에 박스·line 도로 마스크·퍼센트가 표시된다.
- [ ] 분석이 늦으면 동기화 모드에서 대기 후 이어 재생된다.
- [ ] 동기화를 끄면 미분석 구간에 이전 박스·신호 안내가 남지 않는다.
- [ ] 초록은 주행, 노랑은 감속, 빨강은 정지, 미확인은 신호 확인이다.
- [ ] 여러 색이 감지되면 빨강을 우선한다. 신호 없음이 주행으로 표시되지 않는다.
- [ ] 앞뒤 탐색과 반복에서 현재 시각의 결과만 사용한다.
- [ ] 분석 중지 후 이어하기가 완료된 결과를 재사용한다.
- [ ] 표시 임계값·클래스·불투명도 변경은 즉시 적용된다.
- [ ] PNG에는 실제 영상·오버레이·신호 안내가 함께 저장된다. JSON에는 키가 없다.
- [ ] 1920px와 휴대폰 폭에서 버튼·신호 안내·영상이 잘리지 않는다.

API 키·계정 이메일은 캡처하지 않습니다. 실제 주행 판단용이 아닌 학습용 안내이며 퍼센트는 정확도가 아니라 예측 신뢰도입니다. 원본 source.mp4의 학습 장면을 다시 보는 검사는 새 영상의 인식 성능 평가와 구분합니다.
