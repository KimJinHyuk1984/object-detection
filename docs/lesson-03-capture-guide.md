지금 강의의 demo-result.png는 코드로 만든 가상 장면과 예제 결과입니다. 사용자 화면 캡처나 실제 모델 추론으로 소개하지 않습니다.

## 반드시 확인할 항목

- [ ] 예제 모드에서는 키 없이 실행되고 DEMO 표시가 보인다.
- [ ] 임계값·불투명도·클래스 선택을 바꿔도 API를 다시 호출하지 않는다.
- [ ] 새 이미지·모델·모드에서는 이전 결과가 지워진다.
- [ ] line은 차선 사이의 주행 가능 도로 영역이고, 유효한 폴리곤으로 표시된다.
- [ ] PNG·JSON이 열리며 예제 출처와 조건이 맞다.
- [ ] 실제 모델이 준비됐다면 Deploy의 모델 유형·지원 호스팅과 응답 points를 확인한다.
- [ ] 강의 페이지의 ZIP·PDF 다운로드와 발표 모드 18개 조각을 실제 브라우저에서 확인한다.

캡처에 API 키와 계정 이메일이 나오지 않도록 필요한 영역만 저장합니다. 설정 파일은 .streamlit/secrets.toml.example만 공유하며 실제 secrets.toml은 공유하지 않습니다.
