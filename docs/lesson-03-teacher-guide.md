# 3차시 교사용 진행안

주제: API로 이미지 앱 만들기 · 50분 · 18개 발표 조각  
페이지: [3차시](../api-app/index.html)  
현재 사용자 상태: **어노테이션 진행 중**. 실제 모델 ID·키·추론 결과는 아직 확인하지 않았습니다.

## 수업 전 준비

- Python 3.12와 실습 requirements.txt 설치를 미리 마칩니다. 설치 지연을 50분 수업에 포함하지 않습니다.
- [실습 ZIP](../files/lesson-03.zip)을 풀고 app.py가 있는 폴더에서 실행합니다.
- [활동지 PDF](../files/lesson-03-workbook.pdf)는 A4 2쪽입니다.
- 현재는 예제 모드로 진행합니다. 가상 도로와 손으로 작성한 결과이며 실제 모델의 예측이 아님을 먼저 설명합니다.
- 실습 앱은 준비된 코드에서 시작합니다. 수업 중에는 파일 역할·핵심 요청·표시 조건을 읽고 조작합니다.
- 실제 연결은 모델 학습 후 진행합니다. Instance Segmentation과 Serverless 지원, 모델 ID와 line 폴리곤 출력을 확인합니다.

## 50분 진행

| 시간 | 활동 | 결과물 |
| --- | --- | --- |
| 0-8분 | 이미지 → API → 응답 → 화면, 학습·추론·표시 구분 | 흐름 설명 |
| 8-18분 | 앱 파일·실행 명령·예제 첫 화면, 비밀 설정의 역할 | 앱 실행 |
| 18-28분 | 이미지 입력 보정, 모델 호출 코드, 중심 좌표와 points | 응답 구조 설명 |
| 28-42분 | 박스·마스크, 세션 상태, 5분 짝 활동 | 조건 비교 표·PNG |
| 42-50분 | 오류 종류, 체크리스트, 종료 질문 | 오류 분석·다음 시간 준비 |

어노테이션 진행 중인 현재는 실제 설정·요청 절차를 설명하고 예제 모드로 전체 실습을 마칩니다. 실제 연결이 안 됐는데 성공으로 표시하지 않습니다.

## 활동지 비교 기준

모든 클래스를 선택한 예제에서의 값입니다. 실제 모델 성능이 아닙니다.

| 표시 임계값 | 일반 객체 | line 영역 | 합계 |
| --- | --- | --- | --- |
| 0.40 | 7 | 1 | 8 |
| 0.70 | 5 | 1 | 6 |
| 0.90 | 2 | 0 | 2 |

0.40에서 lamp(0.38)가 빠지고, 0.70에서는 motor(0.63)·lampy(0.56)가 더 빠집니다. 0.90에서는 car(0.94)·lampg(0.91)만 남습니다. 불투명도는 점수를 바꾸지 않습니다.

## 핵심 설명과 실습 범위

- 같은 모델 응답에서 일반 객체는 박스, line은 폴리곤으로 표시합니다.
- 입력은 방향 보정·RGB 변환·긴 변 1,600px 제한 후 전송합니다. 응답 이미지 크기에 맞춰 좌표를 배율 변환합니다.
- 모델 ID와 API 키의 역할을 구분합니다. 키는 secrets.toml 또는 환경 변수에 두며 캡처·활동지·Git에 포함하지 않습니다.
- 표시 임계값·불투명도·클래스 변경은 저장된 응답으로 다시 그립니다. 새 API 요청은 분석 버튼을 눌렀을 때만 실행합니다.
- 이미지·모드·모델 ID·키가 바뀌면 기존 응답을 지웁니다. 세션 상태를 다른 학생과 공유하는 전역 캐시로 바꾸지 않습니다.
- line에 유효한 points가 없으면 안내하고 제외합니다. 사각형을 채워 마스크를 만들었다고 설명하지 않습니다.
- 원격 SDK 오류 원문에는 인증 정보가 포함될 수 있어 앱에는 정리한 오류 메시지만 표시합니다.
