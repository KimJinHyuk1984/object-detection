# 3차시 교사용 진행안

주제: API로 영상 테스트 앱 만들기 · 50분 · 18개 발표 조각

페이지: [3차시](../api-app/index.html)  
현재 사용자 상태: **201장 어노테이션·RF-DETR Object Detection (Small) v1 학습·평가 확인**(2026-10-18). 도로 마스크를 위해 Instance Segmentation 모델을 준비합니다. API model_id·요청 코드·실제 추론 결과는 확인 전입니다.

## 수업 전 준비

- 64비트 Python 3.11 또는 3.12와 실습 requirements.txt 설치를 미리 마칩니다. 실행 예시는 3.11 기준이며 3.12 사용 시 첫 줄의 선택 버전만 바꿉니다. 설치 지연을 50분 수업에 포함하지 않습니다.
- [실습 ZIP](../files/lesson-03.zip)을 풀고 app.py가 있는 폴더에서 실행합니다.
- [활동지 PDF](../files/lesson-03-workbook.pdf)는 A4 2쪽입니다.
- source.mp4를 준비합니다. 기본 “영상 업로드 확인”으로 업로드·프레임 추출·MP4 저장을 확인합니다.
- 박스·마스크·임계값은 “예제 결과로 연습”에서 연습합니다. 가상 결과이며 실제 모델 예측이 아님을 설명합니다.
- 실습 앱은 준비된 코드에서 시작합니다. 수업 중에는 파일 역할·핵심 요청·표시 조건을 읽고 조작합니다.
- 현재 탐지 모델에서는 line 마스크가 나오지 않습니다. 분할 모델을 준비하고 Deploy Model의 실제 model_id·요청 코드·Serverless 지원과 line 폴리곤 출력을 확인합니다.

## 50분 진행

| 시간 | 활동 | 결과물 |
| --- | --- | --- |
| 0-8분 | 영상 → 프레임 → API → 결과 영상, 학습·추론·표시 구분 | 흐름 설명 |
| 8-18분 | 앱 파일·실행 명령·영상 업로드·추출, 비밀 설정의 역할 | 앱 실행 |
| 18-28분 | 구간·분석 fps·프레임 크기, 모델 호출 코드, 중심 좌표와 points | 응답 구조 설명 |
| 28-42분 | 박스·마스크, 세션 상태, 5분 짝 활동 | 조건 비교 표·MP4 |
| 42-50분 | 오류 종류, 체크리스트, 종료 질문 | 오류 분석·다음 시간 준비 |

탐지 모델 학습은 완료했으며 분할 모델과 연결 정보를 준비하는 동안 업로드 확인·예제 모드를 나누어 실습합니다. 실제 연결이 안 됐는데 성공으로 표시하지 않습니다.

MP4는 샘플 프레임을 선택 fps로 이어 붙인 무음 확인 영상입니다. 실제 모델 연결 전에는 NO MODEL 표시가 있으며 인식 결과로 설명하지 않습니다.

## 활동지 비교 기준

모든 클래스를 선택한 예제에서의 값입니다. 실제 모델 성능이 아닙니다.

| 표시 임계값 | 일반 객체 | line 영역 | 합계 |
| --- | --- | --- | --- |
| 0.40 | 7 | 1 | 8 |
| 0.70 | 5 | 1 | 6 |
| 0.90 | 2 | 0 | 2 |

0.40에서 lamp(0.38)가 빠지고, 0.70에서는 motor(0.63)·lampy(0.56)가 더 빠집니다. 0.90에서는 car(0.94)·lampg(0.91)만 남습니다. 불투명도는 점수를 바꾸지 않습니다.

## 핵심 설명과 실습 범위

- 같은 모델 응답에서 일반 객체는 박스, line은 폴리곤으로 표시합니다.
- 기본 영상 실습은 시작 0초·10초 구간·2fps로 최대 20프레임입니다. 긴 변 960px, 한 번에 최대 20초·60프레임입니다.
- 보조 이미지 입력은 방향 보정·RGB 변환·긴 변 1,600px 제한 후 전송합니다. 응답 좌표는 전송한 크기에 맞춥니다.
- 모델 ID와 API 키의 역할을 구분합니다. 키는 secrets.toml 또는 환경 변수에 두며 캡처·활동지·Git에 포함하지 않습니다.
- 표시 임계값·불투명도·클래스 변경은 저장된 응답으로 다시 그립니다. 새 API 요청은 분석 버튼을 눌렀을 때만 실행합니다.
- 영상/이미지·구간·fps·모드·모델 ID·키가 바뀌면 기존 응답을 지웁니다. 세션 상태를 다른 학생과 공유하는 전역 캐시로 바꾸지 않습니다.
- line에 유효한 points가 없으면 안내하고 제외합니다. 사각형을 채워 마스크를 만들었다고 설명하지 않습니다.
- 원격 SDK 오류 원문에는 인증 정보가 포함될 수 있어 앱에는 정리한 오류 메시지만 표시합니다.

## 캡처와 검증

데이터·학습·평가 캡처는 수신 완료입니다. [캡처 안내](lesson-03-capture-guide.md)의 업로드·추출·MP4 재생은 지금 확인할 수 있습니다. 분할 프로젝트의 폴리곤 보존을 먼저 확인하고, 분할 학습 후 실제 예측·Deploy 요청 코드를 받습니다.

Python 단위 테스트와 Streamlit AppTest는 수행할 수 있지만 실제 브라우저 화면·키보드 입력·모바일 검사와 다릅니다. 현재 범위는 [검증 기록](lesson-03-verification.md)에 구분합니다.
