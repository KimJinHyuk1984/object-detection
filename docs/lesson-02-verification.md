## 환경과 남은 확인

기본 셸 실행 도구가 환경 초기화 오류로 동작하지 않아 Node REPL의 파일 API와 자식 프로세스로 검사를 수행했습니다. Python이 없어 로컬 HTTP 검사는 Node로 수행했습니다. 브라우저 도구의 인벤토리를 다시 확인했으나 apps=[], browsers=[]여서 실제 화면 검증은 수행하지 못했습니다.

1. 현재 Roboflow 프로젝트 유형·정답 형식의 분할 학습 호환성을 확인합니다. 기존 캡처의 Object Detection 상태가 변경되었다고 가정하지 않습니다.
2. sign·line의 경계 기준과 Dataset 검수·분리를 확인합니다.
3. 실제 버전·학습·평가 화면이 준비되면 [캡처 안내](lesson-02-capture-guide.md)에 따라 반영합니다.
4. 실제 수업 브라우저에서 1·2차시 이동, 발표·모바일·테마·다운로드와 1차시 YouTube 재생을 확인합니다.

수행: 2차시 제작·강의 목록 전환 → 산출물: HTML·스타일·메타·활동지·문서 → 검사: 정적·HTTP 통과 / 브라우저 미실행 → 다음: 어노테이션 검수와 실제 학습 화면 반영. Roboflow 프로젝트 변경·학습·커밋·푸시·호스팅 변경·외부 배포는 수행하지 않았습니다.

## PDF 활동지 추가

사용자 요청으로 기존 TXT 내용을 A4 4쪽 PDF로 편집하고 강의의 활동지 링크 2곳과 README를 PDF로 변경했습니다. 한글 일반·굵은 글꼴을 포함하고 표·체크박스·필기 공간을 배치했습니다. TXT 원문은 보존합니다.

ReportLab으로 생성하고 pypdf로 4쪽·A4·9개 클래스·6개 활동 항목·한글 글꼴 포함을 검사했습니다. Poppler로 전 페이지를 130dpi PNG로 렌더링해 한글·표·여백·페이지 번호·잘림·겹침을 시각 확인했습니다. 루트 및 저장소 하위 경로의 HTML·PDF 총 4개 응답 200과 바이트 일치를 확인했습니다. 실제 브라우저 클릭 검증과 구분합니다.

기존 정적·HTTP JSON과 위의 4,584바이트 기록은 TXT 활동지 단계의 이력입니다. 현재 PDF의 파일 크기·해시·렌더링·HTTP 결과는 [PDF 검증 기록](lesson-02-workbook-verification.json)을 참고합니다. PDF 생성 원본은 scripts/create_lesson02_workbook.py이며, output/pdf 생성본과 files 배포본은 동일합니다. 중간 PNG는 검사 후 정리했습니다.
